## Website To-Do List
Website to-do list menggunakan HTML, CSS, JS untuk Final Project LBE RPL

<img src="./assets/img/preview.png" width=300/>


Core Features:
- Mengubah status task menjadi selesai menggunakan checkbox
- Mengedit deskripsi task
- Filter task berdasarkan status (Semua/Aktif/Selesai)
- Menyimpan data tasks pada `localStorage` sehingga tidak reset saat di-refresh
- Memiliki task count untuk melihat jumlah task tersisa
- Menghapus semua task yang statusnya selesai
- Menambahkan To-Do Task berdasarkan tingkat prioritas dan waktu mengerjakan
- Kompatibel pada platform mobile dan desktop
- Bonus: Toggle Dark Mode
